WebGPU composition + browser AI

WebGPU video with real-time object detection

A browser-native pipeline that decodes video with MediaBunny, composites layers on the GPU with WebGPU, and runs RF-DETR inference on WebGPU inside a dedicated worker. Decoded VideoFrames are transferred to the worker (no canvas readback); bounding boxes are drawn in a second WebGPU pass on top of the composed frame.

  • Decode media Video and audio tracks are decoded in the browser with MediaBunny.
  • Transfer frames Each preview frame clones the decoded VideoFrame and posts it to the worker.
  • Run AI on WebGPU Transformers.js runs RF-DETR in a worker; inference stays off the main thread.
  • Compose on GPU Video, image overlays, then detection boxes — all in WebGPU passes.
  • Preview timeline Play, pause, and scrub; render and detection FPS are shown live.

Demo composition

The preview below uses this timeline (1280×720, 30 fps): one video with audio, plus two transparent PNG overlays from 1s to 3s.

Object detection (RF-DETR · WebGPU)

Model: onnx-community/rfdetr_medium-ONNX via @huggingface/transformers with device: 'webgpu'. Detection runs on the decoded video frame (before image overlays). Only one inference runs at a time; newer frames replace pending work while inference is busy.
